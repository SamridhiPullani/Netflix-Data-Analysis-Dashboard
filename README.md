# Netflix-Data-Analysis-Dashboard

## Project Overview
This project analyzes Netflix content using SQL and Power BI.

## Tools Used
- SQL (MySQL)
- Power BI
- Excel

## Key Insights
- Movies vs TV Shows distribution
- Top 10 countries by Netflix content
- Content ratings distribution
- Content released by year
- Top 10 genres

## Files
- Netflix_Data_Analysis_Dashboard.pbix
- netflix_titles.csv
